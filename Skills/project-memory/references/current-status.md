# 当前状态

仅当项目架构、关键约束或主线进行中事项确实变化时更新 `当前状态.md`。它是导航摘要，不是完整知识库，也不能替代原子记录、当前源码或测试。

1. 先确认要保留的当前事实、全局约束和主要模块导航，并删除已经失效的进行中描述；已有仍有效内容要合并保留。
2. 摘要正文不超过 80 行和 6,000 字符，至少能指向当前架构、关键约束、主线事项和相关原子记录或模块摘要。大型项目只保留全局导航和模块链接，详细历史放入原子记录。
3. 使用以下命令写入，脚本路径从本 Skill 目录解析。写入后运行 `validate`，确认摘要有真实项目内容、链接指向当前记录且没有用目标冒充已落地事实。

   ```bash
   python "<project-memory Skill目录>/scripts/memory_store.py" \
     --vault-root "<Vault根目录>" --project "<项目名称>" \
     set-current --body-file "<摘要文件>"
   ```

如果状态没有实质变化，不要为了刷新日期或填充内容而改写。`当前状态.md` 没有知识摘要的输入指纹检测；SessionStart 注入不表示内容仍然有效。即便知识摘要的指纹未变，也不证明源码、测试或外部事实仍有效；关联代码、接口、依赖或配置变化时，按 [召回与复核](retrieval.md) 重新核实。
